# title-lab：中文標題類型

類型名稱來自吕白《从零开始做内容》：第四章「标题 6 型」（小紅書）、第五章「8 招标题」（短視頻）、第七章「开屏三板斧」。需要書中例句時，讀 `~/.agents/skills/content-from-zero/chapters/` 下的 `ch04-xiaohongshu.md`、`ch05-short-video.md`、`ch07-app-growth-and-splash.md`（不在公開 repo）。

## 標題類型（每種素材條件符合才用）

| 類型 | 素材條件 |
|---|---|
| 數字型 | 有真實的時間、次數、金額或「從 A 到 B」的變化 |
| 實用干貨型 | 文章給讀者能照做的方法或清單 |
| 衝突型 | 作者的經歷和一般看法相反，或文中有兩方對立 |
| 對比型 | 有明確的前後、你我、預期和實際 |
| 對號入座型（點名法） | 讀者是一群能用標籤點出的人（職位、處境、年齡） |
| 疑問法 / 設問法 | 文章回答一個讀者自己也會問的問題 |
| 好奇法 | 素材有一個反常細節，標題露一半，開頭補完 |
| 熱詞法 / 俗語法 / 台詞法 | 題目接得上當下熱詞，或能改寫一句讀者熟悉的話 |
| 惊喜優惠型 | 只在真的有優惠或福利時用 |

## 开屏三板斧（標題主角是人或品牌時加用）

- **特徵放大**：主角有名，放大大家已知的特徵。
- **特徵關聯**：主角是普通人，用他做得最久的一件事當特徵。
- **錨定參考系**：主角是新產品或新做法，拿讀者熟悉的同類來比。

標明時寫成「對比型 + 錨定參考系」這種組合。

## 平台規則

- 小紅書：關鍵詞放標題前段，20 字內；可用數字型、對號入座型；正文開頭重複標題關鍵詞。
- 公眾號 / 部落格：可較長，但前 10 字要有具體名詞或數字；回扣標題式開頭要接得住。
- 不用「震驚」「必看」等空洞強調；數字必須是素材裡的真數字。
