# viral-h5

方法來自吕白《从零开始做内容》ch06。要細節時讀 `~/.agents/skills/content-from-zero/chapters/ch06-viral-h5.md`（只讀，不要把內容抄進輸出）。

H5 會被轉發，靠三個要素，缺一個就不刷屏：

- **情緒**：社會情緒，這段時間大眾共有的心理底色（節點、事件、季節帶出來的）。最重要；沒有它最多小爆。
- **重複**：玩法已經火過一次。換節點、換情緒重做，不發明新形式。
- **炫耀**：用戶的產出能拿去朋友圈晒，替他塑造形象（我去過、我做到、我是這種人）。被別人問「怎麼做的」時，他就成了傳播者。

音樂、設計、動效、技術是表象，不算要素。

## 1. 找情緒

寫出活動上線那幾天大眾在感受什麼：觸發它的節點或事件，加一句用戶心裡的話（例：「疫情讓人覺得死亡很近，想把該做的事做完」）。有網路就去微博熱搜、熱門評論、小紅書熱評找證據，附來源；沒有就標 `假設`。

完成條件：1-3 條情緒，每條有觸發點、心裡話、來源或 `假設`。

## 2. 找可重複的玩法

列 2-3 個已經刷屏過的 H5 或社交玩法（換頭像、生成報告、勾選清單、測試人格、年度總結），寫出它當時火在哪，以及搬到這次的情緒上要換什麼。不確定某案例是否真的火過，標 `待查`，不要編數據。

完成條件：每個玩法有原案例、原節點、這次換掉的部分。

## 3. 設計炫耀點

決定用戶最後拿到的那張圖／那句話是什麼，並回答：

- 他晒出來，朋友看到的是他的哪一面？（體面、有趣、有經歷、有情懷）
- 選項或結果裡有沒有讓人想勾、想晒的項目？至少一半結果要讓人「拿得出手」，難堪的結果不給。
- 朋友看到後，能不能一眼看出怎麼參與？入口要在分享圖上。

完成條件：寫出分享圖的文字內容，和三個問題的答案。

## 4. 輸出

給 1-3 個活動設計。每個設計：

```
### <活動名>
一句話玩法：
流程：進入 → 互動 → 結果頁 → 分享（每步一行）
| 要素 | 落在哪一步／哪個元素 | 具體內容 |
| 情緒 | ... | ... |
| 重複 | ... | 原案例：... |
| 炫耀 | ... | 分享圖文案：... |
風險：最可能不轉發的原因，一條。
```

最後選一個主推，理由寫情緒最對時的那個。補一句：H5 成功率靠數量，建議同一情緒做 2-3 版小成本測試。

完成條件：每個設計的三要素表都填滿，且每格指到流程裡具體一步；任一格空著或只寫「設計好看」，這個設計不交。

## 檢查既有 H5 創意

用戶給的是現成創意時，跳過 1-3，直接填第 4 步的三要素表，空格就是問題，對每個空格給一個補法。
