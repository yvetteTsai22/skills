# Chapter 7: App — 零预算活动运营与开屏三板斧

## Core Idea
没钱没资源也能做活动：**前期内部协同（STAR法则）→ 中期饭圈运营（学对手解决痛点）→ 后期用户激活（奖惩机制）**。开屏文案则靠**特征放大、特征关联、锚定参考系**三板斧。

## Frameworks Introduced
- **案例背景**：腾讯"yoo视频"跨年模板活动，无预算，一个月上线 8 个模板，近万视频，"为偶像打call"模板一周使用 7000+ 次。
- **前期：STAR法则沟通（第1节）**——跨部门要资源不打感情牌：
  - **S**ituation：我方处境（要做什么活动、谁参与、在谈哪些资源）。
  - **T**arget：目的（希望多少用户参与）。
  - **A**ction：需要对方做的具体行动 + 时间节点（官微每天发活动信息、申请 DOKI 资源位）。
  - **R**esult（最重要）：对方能收获什么、对其业绩的帮助。
  - 结果：一周内拿到站内开屏/横幅/赛道位 + 站外腾讯视频官微与明星资源。
- **中期：饭圈运营思维（第2节）**
  1. **精准触达**：官微泛发没人参与 → 直接在每个明星**超级话题**里发帖；私聊活跃粉丝拉进微信群做用户研究。"再好的产品也无法满足所有人，只需满足对我们最重要的人。"
  2. **降低参与门槛（学对手）**：粉丝不愿出镜 → 借鉴抖音跨年总结视频（手指一点出一个字）→ 做"以手入画"明星互动模板，次日上传达峰值。"对手就是最好的老师。"
  3. **带节奏**：盟友关系（建粉丝群、共同目标解锁偶像视频）+ 竞争关系（每天公布各家视频数）+ 一对一教程（前期低门槛，后期提高审核要求）。
- **后期：奖惩机制（第3节）**：无偿打call热情会消散，必须给奖励。
  - 给偶像奖励：总榜 TOP2 可申请开屏福利；发布多的偶像可建专题。
  - 给粉丝奖励：日榜 TOP3 粉丝抽偶像签名照。
  - 原则："能不能吸引流量取决于能否触达精准用户、营销是否新颖、渠道够不够广；流量能不能留下来，取决于他能收获什么。"
- **开屏三板斧（第4节）**——用户决定是否点击只用 0.1 秒：
  1. **知名人物：特征放大法**——放大外貌特征（林志玲不老）、角色（六小龄童=孙悟空、苏大强）、特质（杨超越=锦鲤、萧敬腾=雨神）。
  2. **小人物：特征关联法**——找此人**持续做得最久的一件事**作为特征（一万小时定律）→ 查百度/微信指数 → 指数低就用搜词法/文案狗找关联词 → 1–2 次关联即可得到大众熟知的特征。
  3. **品牌App：锚定参考系**——把新产品和用户熟知的同类品牌做对比（源自价格锚定）。

## Key Concepts
- **饭圈**：围绕某明星的粉丝团体，特性单一、热情极高的圈层用户。
- **超级话题**：微博明星粉丝聚集地，精准触达入口。
- **品牌锚定**：作者从"价格锚定"（奥斯基，1992）衍生的概念，给用户一个尺标。
- **用户研究**：找圈层中最有发言权的个体样本了解痛点。

## Mental Models
- 运营分三段看：**拉得来**（资源+渠道）→ **玩得动**（门槛+节奏）→ **留得住**（奖惩）。
- 卡瓶颈时第一反应：竞品有没有遇到过同样问题？
- 一个看似没特征的人，持续做的事就是他的特征。
- 抽象数字（8%收益）不如参照物（支付宝的2倍）。

## Anti-patterns
- **跨部门打感情牌**：不说清对方收益。
- **只做广覆盖不做精准触达**：官微发两条几乎没人参加。
- **高参与门槛**（要求出镜）。
- **无奖励的长期活动**：20 天后增长乏力。

## Worked Example
**小人物开屏：70多岁配音演员**
1. 只闻其声不见其人，开屏又没声音 → 连看 3 天资料。
2. 发现她至少为 30 多个"太后"配过音："流水的演员，铁打的配音"。
3. 查"太后"月搜索指数仅 460 → 用搜词法发现关联词"后宫"（《芈月传》热播，日均 2000 且月增 20%）。
4. 代入太后视角："孙俪扮演的芈月只是一个小皇后，凭什么比我火？"
5. 文案：**"有我的地方才叫后宫"** —— 粉丝群测试，大家好奇是哪位后宫女王，纷纷点开。

**品牌锚定**：理财App 年化 8%（支付宝 4%）加粗加红也没用 → 改成"利息是支付宝的2倍"，次月数据涨 60%。蒙牛早期广告"向伊利学习，争创内蒙古乳业第二品牌"——借伊利成为"仅次于伊利"的品牌。

## Key Takeaways
1. 要资源时用 STAR，把 Result 讲在对方的 KPI 上。
2. 圈层用户要去他们的聚集地（超话）精准触达，并拉群做用户研究。
3. 参与门槛高时抄竞品的低门槛玩法。
4. 用盟友+竞争关系带节奏，用奖惩维持长期活跃。
5. 开屏：名人放大特征；小人物找"最久的一件事"+关联热词；品牌找参照物锚定。
