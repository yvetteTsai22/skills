# Chapter 1: 底层逻辑：爆款内容的6个底层逻辑

## Core Idea
爆款不靠文笔和一万小时，靠**研究爆款（棋谱）+ 复用时间 + 迁移方法 + 两大创意方法（硬组合、换角色）**。这六条逻辑跨平台通用，是后面所有平台章节的母版。

## Frameworks Introduced
- **一份时间卖5次 / 个人飞轮（第1节）**：让事件A成为B的基础，B为C背书，A+B+C=D，D再反哺A、B、C。
  - 作者的飞轮：**启动轮**（公众号作品建信用）→ **拉客轮**（"在行"咨询积累用户与案例）→ **变现轮**（授课、出书）→ **裂变轮**（课程+书打造个人IP）→ **衍生轮**（方法论迁移到小红书/微博/抖音）。
  - When to use：任何新任务开工前，先问"怎样让它被卖 5 次"，而不是"怎样写得更快"。
- **互动式写作（第2节）**：两周写完一本书的方法。
  - How：①助理从知乎、高赞评论、社群征集约 4000 个问题 → ②筛选合并成 1000+ → ③分类（发现只有 6 类：选题、开头、故事、金句、标题、变现）→ ④关进无手机房间，助理提问、作者回答并录音 → ⑤听众觉得好的扩充，听不懂的再讲一遍，仍听不懂就删 → ⑥录音转文字填入提纲 = 初稿。
  - Why it works：被提问时大脑进入"凭什么问倒我"的反击状态，自动完成最痛苦的"知识萃取"（从肉里剔骨头）。3 天变 3 分钟。
- **书稿必要结构**：引言（为什么要学）→ 案例+方法（每章 ~3 个案例，案例总结方法、方法佐证案例）→ 理论支撑（大师/经典语句）→ 总结提炼。
- **画线率**：读者画线 = "啊哈"瞬间。每章至少 **10%** 内容可被画线（1000 字约 100 字）。易被画线的 4 类：①方法总结 ②俗语 ③共鸣类 ④反常识类。重点打造开头和结尾（虎头猪肚凤尾）。
- **峰终定律（卡尼曼）**：人只记得"峰"和"终"。宜家出口 2 元冰激凌就是"终"。结尾要么讲故事得道理，要么拔高理论层次。
- **研究棋谱（第3节）**："围棋高手80%的时间不是在下棋，而是在研究棋谱。"要写爆款就研究 1000 篇爆款并拆解；要考高分就研究试卷（考纲在往年真题里，2000 页教材只需 100 页）。
- **基于目的拆解 + 找捷径**：做任何事先问"有没有捷径"；和大多数人做法一样 = 陷入低效痛苦竞争（大家比谁的鞋快，你去找车）。
- **知识迁移五步法（第4节）**：零经验团队一个月做出小红书爆款：
  1. 搜集爆款（搜相关词找 500 个）
  2. 分组找共性（4 人一组，分别研究选题/标题/头图/开头的共性）
  3. 分享迭代（从 3 天汇报改为每天汇报，一周后全员分享）
  4. 以量拼概率（每人每天 5 篇，前期拼量不拼质）
  5. 不做一蹴而就的爆款（发布后和同类爆款对比，缺什么补什么，慢慢改成爆款）
  - 公式：**70%和爆款相似 × 足够多的试验品 = 100%成功**
- **硬组合（第5节）**：把两个不相关领域、甚至同领域相反的词硬生生组合，并能解释清楚。
  - 跨界组合：用 A 领域概念解释 B 领域（"人生就是IPO"、梁宁"底层操作系统"）——旧内容穿新外套。
  - 金句：造句游戏（"爱情就是一种放弃"）。
  - 电影：爱情片结构不变，创意在于找"最不能在一起的两种人"。
  - 新媒体两步走：①明确热点主题词（中秋→"团圆"）②找相反主题结合（中秋去墓地→《中秋节那些永远回不去家的人》；父亲节→《没有父亲的父亲节》）。
- **换角色（第6节）**："创意最简单最本质的来源就是换角色。"列出事件中所有角色，放弃被写烂的角度，从无人竞争的角度切入。巅峰之作：《罗生门》（同一事件多视角讲述）。

## Key Concepts
- **知识萃取**：从成功案例提炼方法论的过程，知识工作者最痛苦的一步。
- **画线率**：可被画线内容占比，目标 ≥10%。
- **打破常规**（《让创意更有黏性》）：吸引注意最基本的方法；持续不变的刺激让人视而不见。
- **屁股决定脑袋**：角色一换，观点全变——换角色的心理学依据。
- **赛道思维**：同角度 = 和 1 万人跑同一条百米赛道。

## Mental Models
- 把内容生产当**下棋**：80% 时间研究棋谱（爆款），20% 下棋（创作）。
- 把选题会当**角色清单**：先列角色，再划掉被写烂的那个。
- 把创意当**桥梁工程**：两岸是不可能在一起的两个东西，故事/情绪/解释就是桥。
- 用**飞轮**而不是**流水线**评估项目：只产出一次的工作优先级最低。

## Anti-patterns
- **迷信一万小时/熟能生巧**：不研究爆款的苦练是低效竞争。
- **人海战术想选题**：关一屋子编辑想 100 个选题再讨论——像买彩票。
- **一个人冥思苦想提炼方法**：大概率不如被提问后作答。
- **追求一步成爆款**：应发布后对标迭代。

## Worked Example
**换角色：鹿晗公布与关晓彤恋情（2017-10-08）**
- 四个角色：鹿晗、关晓彤、鹿晗粉丝、路人。
- 全网都在写鹿晗角度（《敢说"大家好，这是我女朋友"的男人加100000+分》）→ 放弃。
- 粉丝角度：微博高赞是"你就不能骗骗我？"这类卑微评论 → 《鹿晗：我花钱买你单身》（无人竞争，轻松爆款）。
- 关晓彤角度：《关晓彤：我为什么配得上鹿晗？》——争议本身带来 10万+。
- 路人角度：《幸好和鹿晗在一起的不是你》——批评过分粉丝，当时该事件最火文章。
- 规律：**社交媒体的高赞评论就是共鸣点**，用它确定每个角色的情绪。

## Key Takeaways
1. 每个项目设计成飞轮，一份时间至少卖 5 次。
2. 写长内容用"征集问题 → 分类 → 被提问录音 → 转文字"的互动式写作。
3. 每章 ≥10% 可画线内容；开头结尾精打磨（峰终定律）。
4. 进入陌生平台：搜 500 个爆款 → 分组找共性 → 每日迭代 → 拼量 → 对标优化。
5. 创意两板斧：硬组合（反差主题词）+ 换角色（无人竞争视角）。
6. 和大多数人做法一样时，立刻停下来找捷径。
