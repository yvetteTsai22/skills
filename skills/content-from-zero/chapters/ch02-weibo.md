# Chapter 2: 微博

## Core Idea
微博运营 = **定位**（昵称、简介、内容垂直）+ **流量**（蹭流量、押热搜）+ **做热搜**（选题、搞笑→走心→升华、个人号首发）。核心信条："高赞内容是通往爆款的高速公路，信高赞内容者得天下。"

## Frameworks Introduced
- **3个维度做好定位（第1节）**
  - **昵称**：一眼看出类别（@笑点菌、@全球旅游攻略、@天府泰剧）。各品类 Top 5–10 大号的共同点就是一目了然。
  - **简介**：进一步表达态度或功能（@投稿："不懂就问，私信投稿"——8 字表明身份 + 给出渠道 + 促成互动）。
  - **内容垂直**："专一"。今天情感明天美食 = 用户无法定位你，也就不关注你（@银教授、@柳三便深耕情话）。
- **蹭流量五法（第2节）**
  1. **复制**：把热点事件的高赞评论复制成自己的微博。"个人的才华永远抵不过大众。"
  2. **投票**：抢不到话题主持人置顶，就立刻做投票；问题 = 热搜话题，选项 = 几条高赞评论观点 + "吃瓜"类中立项（@头条新闻 孙杨禁赛投票，晚 30 分钟仍获近 200 万赞）。
  3. **表情包**：把热点精髓（如"双十一"的吃土、剁手）做成表情包，在纯文字里脱颖而出。
  4. **增量**：提炼高赞核心观点，扩写成长微博，叠加新事件/新素材（宇芽家暴 →"家暴只有0次和无数次"+ 蒋劲夫事件）。
  5. **爆款（另辟蹊径）**：前四种仍和他人同赛道；换路径，如讽刺类内容——不触敏感、骂得高级、爽感高。
- **押热搜**：在综艺弹幕里找集中出现的高赞点 → 提取核心词 → 即当日热搜关键词（《天天向上》化妆、沙溢沈腾传声筒、杨超越"全村的希望"）。
- **上热搜三条件（第3节）**：①符合社会主流价值观 ②首发账号必须是**个人号**，官方号会被限流 ③自行用 `#` 标出词条（方便人工筛选，减少后台编辑工作）。
- **热搜选题两思路**：
  - **总结热点日历**：每年固定节日/纪念日；今年流行的，明年同一时间还会流行（《国庆朋友圈鄙视指南》次年原封不动成微博热搜）。
  - **归类同类型事件**：总结同类事件规律，预测用户关注点（明星分手 → #宣布分手文案大赛#；70 周年阅兵 →"好看的小哥哥小姐姐都上交国家了"）。
  - "传播问题本质上是历史问题"。
- **热搜内容三步：搞笑 → 走心 → 升华**（顺序不能乱）。
- **引爆热搜2步**：①个人号发布含热搜词条的关键内容 ②让两三个大号转发引流，使词条进入后台热搜备选库。

## Key Concepts
- **话题主持人**：热搜词条置顶微博的特权持有者。
- **增量**：在复制高赞的基础上提炼观点并扩写深化。
- **押热搜**：基于弹幕/高赞证据预测当日热搜，不是拍脑袋。
- **热点日历**：需自行总结、不断修正的年度可预测热点时间表。
- **演变性**：热搜内容要有层次地演进，否则昙花一现。

## Mental Models
- 把热搜当**有人工审核的漏斗**：先有流量进入备选库，再靠"#"、价值观、个人号身份过人工筛选。
- 把高赞评论当**已验证的民意样本**：复制、投票、增量都建立在它之上。
- 用"**搞笑→走心→升华**"设计话题生命周期：笑点引讨论，哭点引共鸣，升华给社会意义。

## Anti-patterns
- **企业官方号首发热搜**：被限流。
- **只做三步中的一步**：企业热搜冲进前三又很快掉下来的根本原因。
- **单纯搬运高赞**：用户难以完全认同，要做增量。
- **账号内容杂乱**：用户直接取关。

## Worked Example
**#第一批"90后"还有100天就30了#（2019年9月，热搜榜第一近半天，5.7亿阅读，10.4万讨论）**
- **搞笑**：70/80 后眼里的"小屁孩"也老了，10 后要叫 90 后叔叔阿姨；找银教授、休闲璐等段子手刷 #第一批"90后"还有100天30岁，我还是单身狗#。
- **走心**：焦点转向"30岁了，还一事无成"——真实、普遍的心态，触发共鸣。
- **升华**：请《中国新闻周刊》等权威媒体定调：30 岁只是过程不是终点，"一路风景正好，何必虚掷惊与慌"——从焦虑上升为豁达。

## Key Takeaways
1. 昵称 + 简介 + 垂直内容三者一致，用户才会记住并成为"活粉"。
2. 遇到热点，按复制 → 投票 → 表情包 → 增量 → 另辟蹊径的梯度选打法。
3. 去综艺弹幕找当天热搜词。
4. 维护自己的热点日历与"同类事件档案"，提前备稿。
5. 自造热搜：个人号首发 + 带 `#` + 大号转发 + 搞笑→走心→升华。
