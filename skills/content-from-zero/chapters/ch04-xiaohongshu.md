# Chapter 4: 小红书

## Core Idea
小红书 = 种草社区，笔记使命是**曝光、涨粉、种草**。路径：精准定位 + 号设化 → 先找词再模仿做选题 → 封面图/标题/正文模板 → 选题 + 占词，把品牌植入爆款笔记。

## Frameworks Introduced
- **定位三问（第1节）**：①我是谁？②我能提供什么？③我和别人有什么不一样？（定位 = 给用户一个关注你的理由。）
  - **先发散，再聚焦**：先就擅长点找同类爆款、多发几类，看数据哪类火，再聚焦。"我们的感觉90%都是错的，要敬畏数据，敬畏用户。"
  - **先模仿，再创新**：在爆款框架上二次加工；有爆款能力后再基于兴趣/背景/用户评论做差异化。
- **号设化运营**：昵称、头像、简介随垂类内容调整。教训：某号 30 万赞仅 <2000 关注（转粉率 <1%），而"深夜歌单"转粉率近 10%。"能让用户关注你，一定是因为你能持续提供某类内容。"
  - 命名：**昵称+领域**（"小岳岳的拍照魔法"）/ **昵称+地域**（"大宝姐在日本"）。
  - 简介：**我很特别**（"无美颜无滤镜自然光，口红试色"）/ **我很厉害**（"8年香奈儿柜姐，卖出超过100万支口红"）。
- **爆款选题（第2节）**
  - **核心一：先找词，再模仿**：搜定位关键词 → 点"最热" → 前 20 篇放进文档找重复主题（时尚 Top20 中 3 篇是时尚电影）→ 重复出现的元素必须写进去（"不变的爆款元素"）→ 看高赞留言找增量（"居然没有《穿普拉达的女王》"）。
  - **核心二：必火选题模式**：①**聚合类**（知识点密度极高：《想靠××赚钱，推荐这×本书》、Excel 快捷键大全、去××旅游必备×个App——零粉新号一篇涨 3000+ 精准粉）②**同款类**（明星同款衣物、美食、设备）。
- **爆款笔记三件套（第3节）**
  - **封面图**：单图（颜值高、高清无水印、调亮）/ 拼图（集合 or 对比：电影合集、减肥前后）。封面文字放热点/搜索关键词 + 吸引词（必做、禁忌、学生党…）。配图风格和内容与封面一致。
  - **标题6型**：数字型、实用干货型、惊喜优惠型、冲突型、对比型、对号入座型（见 Worked Example）。
  - **正文**：开头重复标题关键词 + 强调词（建议收藏、吐血整理、看这一篇就够了）；中间按序号罗列、短句、口语化、加小表情、布局场景/需求/结果关键词（参考搜索前 3 篇的关键词）；结尾四件事：①号召点赞收藏 ②号召互动 ③@官方号（@薯队长）+ 话题标签 ④引导关注（持续更新）。
- **种草三步拆解（第4节）**：广告很难火 → 先做"爆款笔记" → 再做"行业类（旅游）爆款笔记" → 最后才做"带品牌名的行业爆款笔记"。
- **选题 + 占词**
  - 选题（占 ≥30% 分量）：①梳理业务关键词（日本、大阪、东京）②搜词取前 50 篇爆款 ③总结出现最多的选题 → 仿写且写得更好（加封面字、加关键词、5 条建议变 10 条带图）。团队每天在群里分享爆款扩充选题库。
  - 占词三维度：**搜索维度**（高搜索量词 + 同词足够多篇 + 总点击量高）/ **笔记维度**（饱和度高、关键词提及多、原创度高、发布时间、停留时长、浏览/收藏/点赞/分享、评论及回复数）/ **用户维度**（会员、品牌合作人、大号权重高）。

## Key Concepts
- **种草**：原本无购买计划，被笔记吸引而对产品产生兴趣；不直接转化，做曝光和引流。
- **转粉率**：关注数/点赞数；号设化不到位时流量被浪费。
- **占词**：用户搜某词时你的笔记排在前面。
- **赞藏比**：赞多藏少易被判刷量。
- **发布时间窗口**：9:00–10:00、12:00–13:00、21:00–22:00。

## Mental Models
- 把小红书当**搜索引擎（类百度 SEO）**：占的热词越多越好，关键词抓取主要看开头和结尾。
- 把高赞评论当**爆款的补丁清单**：它告诉你已火的内容还缺什么。
- 研究任何平台 = 研究**平台对优质内容的定义** + **用户使用习惯**（蛋糕粉去蛋黄的故事：给用户留参与空间）。
- "做好一件事5个细节就够，做爆款要做好50个、100个细节。"

## Anti-patterns
- **账号无信任感**：名字是数字串、简介空白。
- **内容杂乱**：美妆和数码混发。
- **一开始就写品牌广告**："100%做不起来"。
- **违规七条**：非认证号推品牌易限流；踩坑/黑店选题多违禁词；药品功效词；佛牌宗教寺庙词；引流二维码；过多同款图/视频（判抄袭）；赞藏比过高（判刷量）。发布前必查。

## Worked Example
**标题6型句式**
| 类型 | 句式 | 例 |
|---|---|---|
| 数字型 | 《挑战…天达到…》《每天××分钟…》《从…到…》《…系列+数字》 | 《每天5分钟，10天痘痘跑光光》 |
| 实用干货型 | 《答应我，下次…一定要…》《你应该知道的…！！…入门科普》 | 《答应我，下次去海边，一定要这样拍》 |
| 惊喜优惠型 | 先说有多好（明星疯买/销量高）再说有多优惠 | 《明星们疯买的包包，居然只要10元钱》 |
| 冲突型 | 制造"不可能"或悬念 | 《每天都吃肉，结果我瘦了15斤》《跟风买这5件化妆品，你只会越来越丑！》 |
| 对比型 | 找大家常用的参照物 | 《生理期做好这6件事，比红糖水管用1000倍》 |
| 对号入座型（点名法） | 标题写目标人群标签 | 《白羊座有哪些难以启齿的小怪癖？》 |

## Key Takeaways
1. 先定位三问，再号设化（昵称+领域/地域，简介写"特别"或"厉害"）。
2. 选题 = 搜词 → 取最热 20–50 篇 → 找重复元素 → 高赞评论找增量 → 仿写得更好。
3. 聚合类干货和明星同款是必火选题。
4. 关键词放标题、正文、图片标签、结尾话题；开头和结尾最被抓取。
5. 品牌种草走三步：爆款能力 → 行业爆款 → 带品牌的行业爆款。
6. 发布前过一遍违规清单。
