# Chapter 0: 自序 + 前言 — 90%的弯路其实不必走 / 什么是内容

## Core Idea
内容 = 知识点 + 观点；技巧最容易学，真正难的是观点（切入角度）。作者把 6 年内容生涯压缩成**七大原则**，全书只解决一件事：**用标准化的生产模式生产非标品**（独特观点、爆款都是非标品）。

## Frameworks Introduced
- **七大原则**（自序）：
  1. **提高未来时间的产出** — 不追求单位时间效率，而是让每份时间被卖 5 次。
  2. **比同行快10倍** — 0.5 分和 0.6 分的差距不是文笔，是"想通了"。
  3. **寻找不变的东西** — 平台会变，内容本质不变。公式：`70%和爆款类似 × 足够多的试验品 = 100%成功`。
  4. **找到事情的底层逻辑** — 先问清真正目标（"写好作文"≠"考高分"）。
  5. **硬组合** — 把两个不相关甚至相反的东西放在一起，还能解释通。
  6. **不要自嗨** — 找到自我表达和用户需求之间的交集；"我们的感知可能90%以上都是错的"。
  7. **爆款一直在重复** — "太阳底下无新事"；所有的创意，都是记忆的累积。
- **赚钱三种方式**：①一份时间卖一次（工资、单次咨询）②一份时间卖很多次（书、课、写作）③买卖他人时间（当老板）。作者策略是把 ① 不断转化为 ②。
- **内容二分法**（前言）：
  - **知识点** — 答案唯一，分对错。
  - **观点** — 答案不唯一；只有切入点足够深刻、特别，才能激起关注、认同和转发。

## Key Concepts
- **非标品**：独特观点、爆款；本书目标是用标准流程批量生产它。
- **底层逻辑**：跨平台、跨形式都能贯彻的不变规律；"我从来不学表面的东西，因为迟早都会过时"。
- **画龙舟（刘墉）**：观点就是选择站位——岸上、船上、天上俯视；角度独特即胜出。
- **想通了**：从 0.5 分到 0.6 分的唯一门槛。

## Mental Models
- 把观点想成**画龙舟的机位**：技巧（色彩构图）人人可练，机位才是冠军的来源。
- 读者的眼睛是雪亮的：哪里写得不好，留言区基本都有答案——把留言当成免费质检。
- 先问"真正的目标是什么"，再选方法；目标错了，努力全白费。

## Anti-patterns
- **只追求单位时间效率**：天花板低，时间只卖一次。
- **抱怨"读者不懂好文章"**：这是自嗨的信号。
- **学没有实操经验者的书/课**："没写过10万+的文章怎么能教别人写出10万+的文章？"

## Worked Example
**画龙舟**：刘墉让孩子们画端午龙舟。大部分作品只是水彩/水墨、船大船小、有无船桨的差别——全是侧面视角。只有一个孩子画了**正面迎面冲来的龙舟**：窄窄船身、两个挥桨的人、后面弯弯船尾。"无论技术、构图、色彩如何，只论这个角度他就是冠军了。"
→ 套用：写任何热点前，先列出"大家都站在哪儿看"，再故意换一个机位（见 ch01 换角色）。

## Key Takeaways
1. 内容的护城河是观点而不是技巧；先找角度再动笔。
2. 每做一件事先问：这件事能不能被卖 5 次？不能就想办法规避。
3. 把精力放在不变的东西上：爆款规律跨平台通用。
4. 敬畏用户反馈，自我表达必须落在用户需求的交集里。
5. 成功是概率问题：贴近爆款 70% + 大量试验。
