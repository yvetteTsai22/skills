# Chapter 3: 微信 — 开头、结构、结尾、故事、金句模板

## Core Idea
公众号爆文是一套可套用的模板系统：**8个开头模板 + 4个结构模板 + 4个结尾套路 + 4+3+2故事模板 + 7个金句方法**。会套模板 = 10 分钟出框架、2 小时发稿，比同行快 100 倍。

## Frameworks Introduced
### 8个开头模板（第1节）—— 前三句抓不住，后面写再好也白费
| # | 模板 | 要点 |
|---|---|---|
| 1 | **问句式** | 疑问/反问/设问；①制造悬念 ②加强情感 ③承上启下（承标题、启下文）。问句不一定放第一句 |
| 2 | **对话式** | 把文中最有爆点的人物对话前置；简短、精炼、抓人（"四川好可怕"） |
| 3 | **点名式** | 作者与读者对话，多用"你""大家"，营造好友闲聊感 |
| 4 | **自我剖析式** | 第一人称；两技巧：①自黑自嘲 ②你做的事很特别（"2016年，我30岁。未婚，无房，无存款"） |
| 5 | **回扣标题式** | 开头紧扣标题关键词，解答标题留下的疑惑 |
| 6 | **名句式** | 直接引用 或 **解构名句**（"美的人都彼此相似，丑的人却丑得千奇百怪"），借名句的晕轮效应 |
| 7 | **用户留言式** | 表明"本文来自读者征集"，留言者会回来找自己，事例天然典型 |
| 8 | **时事热点式** | 用热点人物/事件/影视开篇，读者"爱屋及乌" |

### 4个结构模板（第2节）
1. **1个观点 + N个事例**：观点在标题/开头 → 多个故事印证 → 结尾重述观点 + 行动召唤。事例要能论证且有传播度，别太生僻。
2. **总论点 + 分论点**：适用于观点足够吸引人；分论点不能背离总论点；结尾辩证分析反常规观点。
3. **1个观点 + N个角度**：适用于素材丰富（可靠读者征集获得素材）；从不同角度/场景描绘；结尾拉回现实或"写在最后"金句。
4. **1个观点 + 同一个人的多个事迹**：人物生平丰富且高度契合观点；也是**抢热点最快**的写法（热点人物出现时写主角故事）。

### 4个结尾套路（第3节）—— 峰终定律的"终"
1. **概括式**：①总结核心观点 ②用金句升华 ③呼吁行动。
2. **点名式**：多用"你"，关联读者切身利益/祝愿。
3. **名句式**：结尾引用/解构名言，增加说服力和意境。
4. **排比句式**：气势强；尽量与前三种结合使用。

### 4+3+2故事模板（第4节）
- **4步搞定故事**（骨架）：①**一句话**（开头+结果）②**定冲突**（灵魂）③**给理由**（为什么冲突会发生）④**来组合**。
- **3点完善故事**（血肉）：①交代故事背景 ②补充核心信息 ③**触发情绪爆点**（最关键）。
- **2招引爆故事**：①**打乱顺序**（插叙/倒叙，《低俗小说》《盗梦空间》《想见你》）②**场景演绎**（不写"我很难过"，写场景）。

### 7个金句方法（第5节）—— 形式（对称/工整/押韵）+ 内容（内涵/共鸣）缺一不可
1. **1221句式**：两个核心词前后半句语序颠倒（"给岁月以文明，而不是给文明以岁月"）。4 原则：①重新定义 ②抓住从属关系 ③利用反义词 ④变换主被动。
2. **1213句式**：重复部分 + 两个不同成分（"为你明灯三千，为你花开满城"）。两思路：①核心词相反关系（先"找场景"）②核心词递进关系（"有的歌，听的是音符；有的歌，听的是情怀"）。
3. **拆字法**：拆汉字部件重组成符合原字义的句子（"我摊开心中愁，你只见眼前秋"）。
4. **搜词法**：搜含同一字的词组合（"过了明天，就是天明""去征服所有不服"）；工具：百度、"文案狗"。
5. **具象法**：化抽象为场景/事物/动作（"越是被别人捂住嘴，越要大声吼出来"胜过"越是不让发声，越要发声"）。
6. **否定法**：**完全否定**（"时间不是药，但药藏在时间里"）/ **半否定**（海明威"我同意前半句"）。被否定的句子要传播度高。
7. **押韵**：韵脚一致（朱广权"地球不爆炸，我们不放假"）；读世界十大演讲练语感。

## Key Concepts
- **场景演绎法**：写作时代入场景，问性别/性格/反应/职业/环境，用细节代替情绪词。
- **品效结合**：品牌金句要带品牌名（"后来的我们……"），否则爆了也没用。
- **半熟悉半不熟悉**：人最喜欢的内容熟悉度，是否定法生效原理。
- **模板组合**：开头/结构/结尾模板可叠加，产生 1+1>2。

## Mental Models
- 把一篇文章看成**乐高**：开头块 × 结构块 × 结尾块 × 故事块 × 金句块，按素材条件选块。
- **选结构的决策**：观点够炸 → 总分；素材多 → N个角度；有热点人物 → 同一人多事迹；默认 → N个事例。
- 写情绪时问："镜头里能拍到什么？"——拍不到的情绪词都要换成场景。

## Anti-patterns
- **开头自嗨**：自说自话，不抓用户关心点。
- **想到哪写到哪**：没有结构模板，文章无逻辑。
- **结尾乏力**：打开率高但转评赞低的主因。
- **金句只有形式没内容**："好看的塑料花瓶"。
- **否定冷门句子**：没有"理所当然"感，激不起兴趣。

## Worked Example
**1213句式 —《后来的我们》宣传语（只拿到一张海报）**
1. 找场景：海报是候车厅里依偎的一男一女，背景人来人往。
2. 选词：情侣 →"对方"；为押韵，"时间"换成"时光"；回家 →"家"不够好 → 同义词"故里"。
3. 套句式 + 核心词相反：
   > 后来的我们，为了谁四处迁徙，为了谁回到故里？
   > 后来的我们，有多少衣锦还乡，有多少放弃梦想？
   > 后来的我们，有多少跑赢了时光，有多少弄丢了对方？
4. 品效结合：每句都嵌入片名"后来的我们"。

**4步故事 —《肖申克的救赎》**：一句话（安迪被诬陷入狱，最后成功越狱）→ 定冲突（想上诉出狱，遭监狱长阻挠）→ 给理由（安迪帮他偷税漏税干得太好）→ 来组合。

## Key Takeaways
1. 开头前三句定生死：从 8 个模板里选，不要从零想。
2. 先按素材条件选结构模板，再填事例。
3. 结尾 = 概括 + 金句 + 行动召唤，可叠加点名/名句/排比。
4. 故事先搭"一句话—冲突—理由"骨架，再加背景、核心信息、情绪爆点，最后打乱顺序 + 场景化。
5. 每篇至少用 1–2 个金句模板制造"可画线"句子。
