# Chapter 5: 短视频

## Core Idea
短视频爆款 = 避开四大误区 + 反差定位 + 十大元素选题 + 人格化人设 + **黄金3秒 + 2～5个爆点 + 白金结尾** + 好标题 + 经营留言区。评论是互动率中权重最大的项，一切设计都为制造评论点。

## Frameworks Introduced
- **四大误区（第1节）**：①**自嗨**（只拍自己喜欢的，缺用户思维）②**不够专一**（什么都发，用户和平台都无法归类）③**没有特点**（和别人一样的街访，连 logo 都没有）④**没有梗**（李佳琦"买它！""所有女生"；梗要反复出现）。
- **五大定位方法（第2节）**——本质都是"打破常规"：
  1. **年龄反差法**：行为与年龄不符（北海爷爷精致穿搭、时尚奶奶团）。
  2. **性别反差法**：男扮女装/女扮男装（多余和毛毛姐）。
  3. **场景切换法**：日常事换场景做（办公室小野用熨斗做烤冷面、乡村胡子哥溪边做饭、李子柒）。
  4. **典故定位法**：以传说人物为人设（月老玄七、孟婆十九、仙女酵母）。
  5. **影视剧定位法**：把影视剧中火过的人设搬进现实（爆款重复）。
- **爆款十大元素（第3节）**：**3种情感**（爱情、亲情、友情）+ **5种情绪**（愤怒、怀旧、愧疚、暖心、爱国）+ **2个因素**（地域、群体）。元素组合交叉 = 新爆款。
- **四大选题法**：
  1. **热点日历选题法**：节日必发相关内容（过年吃饺子日常也能爆）。
  2. **高赞视频选题法**：剪辑经典长视频精华（《乡村爱情》"她扒拉我"；名侦探小宇改编《今日说法》——专业团队打磨的内容对普通内容是"降维打击"）。
  3. **高赞图文选题法**：精美图片/句子图配文案+音乐（书单号）。
  4. **高赞评论选题法**：搬运/演绎网易云等高赞评论（"网易云热评墙"、"这是TA的故事"）。
- **人设构建（第4节）**：借编剧方法分**主要人物、次要人物、群像式人物**。步骤：找优势 → 定身份 → 提炼特长 → 放大独有特点做成标签 → 输出有亮点的内容。人设可迭代（祝晓晗：跳舞 → 加老爸 → 加老妈 → 衍生"老丈人说车"）。
  - 主页四件套：**昵称**（辨识度+相关性+趣味，或用真名做品牌）/ **头像**（与昵称简介关联、不重复）/ **简介**（一句概括定位；自嘲可化缺点为标签："专业毁舞一百年的157cm82斤的小黑猴"）/ **视频封面**（风格统一，如氪金研究所）。"始于颜值，陷于才华，忠于人品"。
- **内容结构（第5节）**：
  - **黄金3秒**：直接抛激烈矛盾，减少铺垫——最痛恨的行为（老人插队）、激烈争吵、引人深思的问题（你有没有爱过渣男）、热点事件。
  - **2～5个爆点**：足够多的信息点 = 足够多的评论点（地铁牵手视频里夸张笑容的路人；主持人把书拿倒）。模仿爆款时去评论区找精髓。
  - **白金结尾**：①**互动式**（"你有没有一个念念不忘的前任？"）②**共鸣式**（"多少友情都被时间打败，但是我们没有"）③**反转式**。
- **互动率公式**：`互动率 = [(点赞+评论+转发)/观看人数] × 完播率(看完人数/观看人数)`；评论权重最大。
- **8招标题（第6节）**：疑问法、数字法、热词法、俗语法、设问法、电影台词法、好奇法、对比法。
- **留言区运营（第7节）**：①回复他人引共鸣（孟婆十九"已经给姥姥的孟婆汤里加了糖"获赞几十万）②给他人评论立人设（"美女鉴定机"、"叔叔给你刷游艇"大爷）③给自己评论带节奏（悬疑反转视频埋"看不懂啊""谁能帮我解释一下""？？？"，引好为人师者答疑）。

## Key Concepts
- **用户思维**：找自我表达和用户需求的交集。
- **梗**：让人第一时间想到你的话/动作，必须反复出现。
- **降维打击**：用专业团队打磨过的影视内容做短视频素材。
- **流量池**：前 3 秒被划走则不进入下一级推荐池。
- **疑问法 vs 设问法**：疑问法问句 = 内容概括；设问法问句 = 内容一部分，答案在视频里制造反差。

## Mental Models
- 每 1 秒都关系内容密度与节奏——用剪辑表倒推：0–3 秒矛盾，之后每几秒一个爆点。
- 设计爆点 = 设计**评论区会讨论什么**。
- 标题是视频的第二个内容：10 秒空镜头酒店餐桌靠"女孩子暑假打工一定要尝试到高档点的酒店当一次服务员…"获 52 万赞。
- 定位 = 打破常规：先找"大家默认是什么"，再把年龄/性别/场景/典故反过来。

## Anti-patterns
- **视频像日记**：琐事堆砌、追求大场面却不会讲故事。
- **内容什么都发**：平台无法归类扶持。
- **模仿只学形式**：没学到原视频的爆点（书拿倒了）。
- **平铺开头**：3 秒没矛盾就被划走。

## Worked Example
**《才不是老人变坏了，我老马，给老头正名！》（零粉新号首条，播放 >1000万）**
- 黄金3秒：老人直接插队等公交，被问凭什么——"凭我是你大爷"（坏人变老，矛盾抛出）。
- 爆点1：女孩打车想躲开，大爷强行同车。
- 爆点2：大爷强令司机改道，女孩气得下车（加剧冲突）。
- 爆点3：女孩收到大爷纸条：你被跟踪了，身后排队的人和司机是一伙的（解释插队）。
- 白金结尾：女孩拿出电话邪魅一笑："大爷上车了"（反转 + 引讨论：女孩是坏人？局是套大爷的？）。

## Key Takeaways
1. 先排查四大误区：自嗨、不专一、没特点、没梗。
2. 用五大反差法之一定位，人设靠主页四件套固化。
3. 选题至少命中十大元素中的 1–2 个，多元素组合更易爆。
4. 结构：3 秒矛盾 + 2～5 个爆点 + 互动/共鸣/反转结尾。
5. 一切以评论数为目标设计，并主动经营自己和他人的评论区。
