## Core Frameworks & Mental Models

**全书目标**：用标准化的生产模式生产非标品（独特观点 = 非标品 = 爆款）。内容 = 知识点（有对错）+ 观点（看切入角度）；技巧好学，观点难。

### 1. 成功公式 — 寻找不变的东西
`70%和爆款相似 × 足够多的试验品 = 100%成功`。平台会变，爆款逻辑不变。成功是概率：贴近已验证爆款 + 拼量 + 发布后对标迭代。不要追求一步成爆款。

### 2. 研究棋谱
"围棋高手80%的时间不是在下棋，而是在研究棋谱。" 想写爆款就拆 1000 篇爆款；想考高分就研究真题。和大多数人做法一样时 → 停下找捷径。

### 3. 高赞内容是通往爆款的高速公路
高赞评论 = 已验证的共鸣点。用它：确定角色情绪（换角色）、复制/投票/增量（微博）、找爆款缺口（小红书"居然没有《穿普拉达的女王》"）、找视频爆点（"书拿倒了"）、预测热搜（综艺弹幕）。

### 4. 两大创意方法
- **换角色**："创意最简单最本质的来源"。列出事件全部角色 → 放弃被写烂的角度 → 无人竞争的赛道（鹿晗恋情：《鹿晗：我花钱买你单身》）。
- **硬组合**：把不相关甚至相反的东西组合并解释通。取热点主题词 → 组合反义主题（中秋团圆 →《中秋节那些永远回不去家的人》）；或跨界概念外套（人生就是IPO）。

### 5. 不要自嗨 · 爆款一直在重复
找自我表达与用户需求的交集；"我们的感知90%以上都是错的"，敬畏数据。所有创意都是记忆的累积（圣诞帽 → 国旗头像）。

### 6. 一份时间卖5次（飞轮）
启动轮(作品) → 拉客轮(咨询) → 变现轮(课/书) → 裂变轮(IP) → 衍生轮(跨平台)。动手前问：这件事能被卖 5 次吗？
**互动式写作**：征集问题 → 分类 → 被提问录音 → 转文字成稿（知识萃取 3 天变 3 分钟）。

### 7. 峰终定律 + 画线率
读者只记得高峰与结尾；每章 ≥10% 可画线（方法总结、俗语、共鸣、反常识）。开头结尾精打磨。

### 8. 公众号写作模板系统（ch03）
- **8开头**：问句、对话、点名、自我剖析、回扣标题、名句、用户留言、时事热点。
- **4结构**：1观点+N事例 / 总论点+分论点 / 1观点+N角度 / 1观点+同一人多事迹。
- **4结尾**：概括（总结→金句→行动）、点名、名句、排比。
- **4+3+2故事**：一句话→定冲突→给理由→组合；背景、核心信息、情绪爆点；打乱顺序、场景演绎。
- **7金句**：1221、1213、拆字、搜词、具象、否定、押韵。

### 9. 平台打法速记
- **微博**：定位（昵称/简介/垂直）；蹭流量五法（复制、投票、表情包、增量、另辟蹊径）；押热搜；热搜=个人号首发+`#`+大号转发，内容**搞笑→走心→升华**。
- **小红书**：定位三问（我是谁/能提供什么/有何不同）+号设化；先找词再模仿；必火选题=聚合类+同款类；封面+标题6型+正文开中结；选题+占词；品牌种草三步走。
- **短视频**：四大误区（自嗨、不专一、没特点、没梗）；五大反差定位（年龄、性别、场景、典故、影视剧）；**十大元素**（爱情亲情友情 / 愤怒怀旧愧疚暖心爱国 / 地域群体）；**黄金3秒 + 2～5个爆点 + 白金结尾**；8标题法；经营留言区。互动率中评论权重最大。
- **H5**：社会情绪 + 爆款重复 + 用户参与（可炫耀）。
- **App**：STAR 要资源 → 超话精准触达+降门槛+带节奏 → 奖惩留存；开屏三板斧：特征放大、特征关联、锚定参考系。

### 应用规则
- 选角度先于写作：先找"龙舟的正面机位"。
- 一切设计都问："评论区会讨论什么？"
- 模板是"紫薇软剑"：先用来横行天下，守住不作恶的底线；内功成后弃剑，"无剑胜有剑"。
