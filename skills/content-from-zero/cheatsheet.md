# Cheatsheet — 吕白的决策规则

## 动手前三问
- 这件事能被卖 5 次吗？不能 → 改造成能，或规避。
- 我的做法和大多数人一样吗？是 → 停下找捷径（找车，不找鞋）。
- 真正目标是什么？（写好 ≠ 考高分；爆款 ≠ 好文笔）

## 选角度
- 热点出现 → 列所有角色 → 划掉最热的那个 → 用该角色高赞评论定情绪。
- 节日热点 → 主题词取反（团圆→回不去家）。
- 想不出新意 → 旧内容 + 跨界概念外套（底层操作系统、IPO）。

## 选结构（公众号）
| 条件 | 用 |
|---|---|
| 观点本身够炸 | 总论点+分论点 |
| 素材多（读者征集） | 1观点+N角度 |
| 有热点人物 | 1观点+同一人多事迹（最快抢热点） |
| 默认 | 1观点+N事例 |

## 选开头
| 想达到 | 用 |
|---|---|
| 制造悬念 | 问句式 / 对话式 |
| 拉近距离 | 点名式 / 自我剖析（自黑或做了特别的事） |
| 标题看不懂 | 回扣标题式 |
| 观点犀利怕被反驳 | 名句式（借权威） |
| 有读者素材 | 用户留言式 |
| 有热点 | 时事热点式 |

## 热点打法梯度（微博）
复制 → 投票 → 表情包 → 增量 → 另辟蹊径。越往后越差异化。

## 硬性规则 / 阈值
- 爆款 = 70%相似 × 足量试验；第一周无效果正常，第二周起爆。
- 画线率 ≥10%（1000字≈100字）。
- 开头前三句定生死；短视频前 3 秒定流量池。
- 短视频 2～5 个爆点；评论权重最大。
- 热搜：个人号首发 + `#` + 2–3 大号转发；搞笑→走心→升华顺序不可乱。
- 小红书选题 ≥30% 决定成败；发布 9–10 / 12–13 / 21–22 点。
- 小红书转粉率 <1% = 号设化失败（参考值近 10%）。
- 新人每人每天 5 篇拼量。

| 平台 | 核心杠杆 | 关键动作 |
|---|---|---|

## 选题十大元素（短视频）
情感：爱情/亲情/友情 · 情绪：愤怒/怀旧/愧疚/暖心/爱国 · 因素：地域/群体。命中越多越易爆。

## 热点日历要点
1月元旦/春节(回家团圆催婚) · 2月情人节/开学 · 3月女生节/妇女节/315 · 4月愚人节/清明 · 5月劳动节/青年节/母亲节/520 · 6月儿童节/高考/父亲节/618 · 7月暑假 · 8月七夕/男人节 · 9月开学/教师节 · 10月国庆/中秋/重阳/万圣 · 11月双十一/感恩节 · 12月双十二/冬至/圣诞/跨年。单身视角可反用于所有恋爱节日。

## 危险信号（Tells）
- "读者不懂好文章" → 你在自嗨。
- 点赞高、关注低 → 号设化不到位/内容不垂直。
- 打开率高、转评赞低 → 结尾弱。
- 热搜冲进前三又快速掉 → 少了走心或升华。
- 模仿爆款却不火 → 没抓到评论区指出的那个爆点。
- 数据涨不动的活动 → 缺奖励或门槛太高。
- 小红书突然没流量 → 先查违规清单（品牌词、药效、宗教、二维码、同款图、赞藏比）。
