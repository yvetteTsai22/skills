# Glossary — 从零开始做内容

**1213句式** — 重复部分 + 两个不同成分的金句结构（为你明灯三千，为你花开满城）；核心词相反或递进 (Ch 3)
**1221句式** — 两个核心词在前后半句语序颠倒的金句（给岁月以文明，而不是给文明以岁月）(Ch 3)
**2～5个爆点** — 每条爆款短视频应有的信息点/评论点数量 (Ch 5)
**4+3+2故事模板** — 4步搞定故事、3点完善故事、2招引爆故事 (Ch 3)
**70%和爆款相似 × 足够多的试验品 = 100%成功** — 全书核心成功公式 (Ch 0, 1, 6)
**STAR法则** — Situation/Target/Action/Result，跨部门要资源的沟通结构 (Ch 7)
**白金结尾** — 短视频结尾：互动式、共鸣式、反转式 (Ch 5)
**爆款重复** — 爆款总在跨时间、跨平台重复；H5三要素之一 (Ch 0, 6)
**蹭流量** — 复制、投票、表情包、增量、另辟蹊径五法 (Ch 2)
**拆字法** — 拆汉字部件重组成表达原字义的金句 (Ch 3)
**占词** — 让笔记在某关键词搜索结果中排前 (Ch 4)
**底层逻辑** — 跨平台、跨形式不变的规律 (Ch 0, 1)
**定位三问** — 我是谁、我能提供什么、我和别人有什么不一样 (Ch 4)
**飞轮效应** — 启动轮→拉客轮→变现轮→裂变轮→衍生轮，互相反哺 (Ch 1)
**否定法** — 完全否定或半否定常识句以制造好奇 (Ch 3)
**峰终定律** — 人只记得高峰与结尾体验；结尾要精打磨 (Ch 1, 3)
**高赞评论** — 已验证的共鸣点；选题、增量、找爆点的依据 (Ch 1, 2, 4, 5)
**梗** — 让人第一时间想到你的口头禅/动作，需反复出现 (Ch 5)
**号设化运营** — 昵称、头像、简介随垂类内容调整以提高转粉率 (Ch 4)
**互动率** — [(点赞+评论+转发)/观看]×完播率；评论权重最大 (Ch 5)
**互动式写作** — 征集问题→被提问→录音转文字成稿 (Ch 1)
**画线率** — 可被读者画线（"啊哈"瞬间）的内容占比，目标≥10% (Ch 1)
**换角色** — 列出事件所有角色，从无人竞争视角切入 (Ch 1)
**黄金3秒** — 短视频开头直接抛矛盾 (Ch 5)
**具象法** — 把抽象概念化为场景、事物、动作 (Ch 3)
**品牌锚定** — 用熟知品牌做参照物（支付宝的2倍）(Ch 7)
**品效结合** — 品牌文案的金句须带品牌名 (Ch 3)
**热点日历** — 年度可预测节日/纪念日热点表 (Ch 2, 5)
**人设** — 主要/次要/群像人物 + 主页四件套构建的人格化IP (Ch 5)
**社会情绪** — 当下大众共有情绪；H5最重要要素 (Ch 6)
**十大元素** — 3情感（爱情亲情友情）+5情绪（愤怒怀旧愧疚暖心爱国）+2因素（地域群体）(Ch 5)
**搜词法** — 搜含同字的词组合金句；也用于找关联热词 (Ch 3, 7)
**特征放大法/特征关联法** — 名人放大已知特征；小人物以"持续最久的事"关联热词 (Ch 7)
**研究棋谱** — 80%时间研究爆款而不是闷头写 (Ch 1)
**押热搜** — 从综艺弹幕高赞点预测当日热搜 (Ch 2)
**硬组合** — 把不相关或相反的两者组合并解释通 (Ch 0, 1)
**增量** — 提炼高赞观点后扩写深化，或在爆款基础上补用户缺的内容 (Ch 2, 4)
**知识迁移五步法** — 搜爆款→分组找共性→每日迭代→拼量→对标优化 (Ch 1)
**种草** — 无购买计划者被笔记激发兴趣 (Ch 4)
**自嗨** — 只顾自我表达、忽视用户需求 (Ch 0, 3, 5)
**紫薇软剑** — 后记比喻：模板是入门剑，内功成后弃剑 (Ch 0)
