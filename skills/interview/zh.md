# 訪談：中文

方法來源：吕白《从零开始做内容》的「互动式写作」：先收集讀者會問的問題，作者被提問、邊講邊錄，最後把講出來的話整理成稿。被提問時，作者會自動把經驗裡的骨頭剔出來，比自己對著空白頁想快得多。這裡把它縮成一對一、一次一題。細節需要時讀 `~/.agents/skills/content-from-zero/`（不在公開 repo）。

## 怎麼問

- **用讀者的口吻問。** 書裡的問題來自讀者的提問；你問的也該是讀者真的會問的事（「那你當時怎麼辦？」），不是寫作課的題目（「你的核心論點是什麼？」）。
- **講不清楚就再問一次。** 回答太抽象、聽不懂時，換個說法再問，要一個具體的時刻：「那天發生了什麼？」「你看到的數字是多少？」
- **要原話，不要整理。** 作者講的口語就是素材；方言、口頭禪、自嘲都保留，交給後面的寫作步驟去用。
- **建議答案只用作者已經講過的內容。** 寫「我猜是……，對嗎？」，讓作者改正；作者一改，往往就把真細節說出來了。

## 各欄位的提問範例

| 欄位 | 範例 |
|---|---|
| 核心觀點 | 「如果讀者只記得一句話，你希望是哪一句？」 |
| 時間線 | 「從頭講一遍：前後經過哪幾個階段，每次變了什麼？」 |
| 為什麼是你 | 「這件事你做過、別人沒做過的是什麼？」 |
| 故事 | 「最早發現不對勁是哪一天？當時你在哪、在做什麼？」 |
| 數字 | 「『很多』大概是多少？之前和之後各是多少？」 |
| 反駁 | 「最不同意你的人會怎麼說？你怎麼回？」 |
| 不確定 | 「哪部分你自己也還沒想清楚？」 |
