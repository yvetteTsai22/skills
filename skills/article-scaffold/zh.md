# article-scaffold：中文模板與選用規則

模板名稱和選用規則來自吕白《从零开始做内容》第三章（開頭、結構、結尾模板）和第一章（畫線率、峰終定律）。需要書中的例子時，讀 `~/.agents/skills/content-from-zero/chapters/ch03-wechat-writing-templates.md`（不在公開 repo）。

## 開頭（選一個，可疊第二個）

前三句決定讀者留不留下。依素材選：

| 模板 | 素材條件 |
|---|---|
| 問句式 | 有一個讀者自己也會問、而文章會回答的問題 |
| 對話式 | 有一句真人說過的話，本身就是全文最有張力的一刻 |
| 點名式 | 讀者和作者處境相同，能直接用「你」對話 |
| 自我剖析式 | 作者的處境具體、反常，或願意自嘲；用時間、數字開場 |
| 回扣標題式 | 標題留下疑問，開頭第一段就接住 |
| 名句式 | 有一句讀者熟悉的話，可以引用或改寫來反駁 |
| 用戶留言式 | 素材來自讀者留言或徵集 |
| 時事熱點式 | 題目接得上正在發生的事件或人物 |

規則：開頭優先放高峰素材（對話式、自我剖析式最常接得住）。不要用作者的觀點開頭，先給場景或數字。

## 結構（選一個）

| 模板 | 素材條件 |
|---|---|
| 1 個觀點 + N 個事例 | 預設選項。有一個觀點、兩個以上能印證它的故事 |
| 總論點 + 分論點 | 觀點本身夠反常、夠吸引人，能撐起分論點；結尾要辯證回應反面 |
| 1 個觀點 + N 個角度 | 素材多而散，可從不同場景或不同人看同一件事 |
| 1 個觀點 + 同一個人的多個事蹟 | 素材集中在一個人身上，而且他的經歷高度貼合觀點 |

決策順序：觀點夠反常 → 總分；素材集中在一人 → 同一人多事蹟；素材多而散 → N 個角度；其餘 → N 個事例。

個人部落格的單一經歷（一個決定、前後變化、代價）通常走「1 個觀點 + N 個事例」，把同一段經歷拆成幾個時間點當事例；作者的疑慮或代價放在最後一個事例，當作辯證。

## 結尾（選一個，可疊）

| 模板 | 素材條件 |
|---|---|
| 概括式 | 收束核心觀點；只有當觀點還沒在正文裡說滿時才用 |
| 點名式 | 能把結論接到讀者自己的處境，用「你」 |
| 名句式 | 有一句可引用或改寫的話，正好承接全文 |
| 排比句式 | 只和前三種疊用；排比在部落格容易像 AI 寫的，最多一組 |

規則：

- 書中的結尾配方是「概括 + 金句 + 行動召唤」。部落格裡改用：回到開頭的場景或人物，或停在作者的疑慮上；概括最多一句。
- 結尾要有一句可被畫線的話，但要落在具體的名詞或細節上，不是口號。
- 全文畫線率目標 10%，重點在開頭和結尾（虎頭、豬肚、鳳尾）。

## 平台差異

- 小紅書：開頭用自我剖析式或點名式，第一句就給數字或處境；結構壓縮成 3–5 個短段，一段一個事例；結尾用點名式或提問，引導留言。
- 長文（公眾號、部落格）：照上面完整流程。
