# viral-teardown: English

Researched from English sources, borrow tier (see Sources). Not a translation of the Chinese method.

## The idea: study what already won

- **Swipe file**: copywriters keep a collection of tested, proven ads and headlines and model new work on them.
- **Skyscraper technique**: find content that already earned links, then make something clearly better (more current, more complete, better visuals).
- **Pattern counting at scale**: BuzzSumo finds headline patterns by counting recurring three-word phrases across top-shared headlines, using medians and one instance per domain so one big site does not dominate.

Borrow all three: collect proven pieces, count what repeats, ship a better version.

## Where to pull top pieces

- Hacker News: hn.algolia.com, search the keyword, sort by popularity.
- Reddit: the topic's subreddit, Top, All time or Past year.
- Newsletters/blogs: most-shared posts on the keyword (BuzzSumo if available), Medium top stories for the tag.
- YouTube or TikTok: keyword search sorted by view count.
- One piece per author or domain, so one prolific writer does not set the patterns.

## Tags per piece

- Headline shape: number list, how-to, "you need to", superlative (best/most), question, contrarian, personal result ("I did X for N days").
- Recurring three-word phrases in the headline.
- Opening: anecdote, bold claim, question, data point.
- Structure: list, narrative, tutorial, case study, comparison.
- Emotion: curiosity, fear of missing out, status, relief.
- Ending: call to action, question, summary line.

## Using the result

- A pattern in many top pieces is table stakes: include it.
- Top comments asking "what about X" mark the gap for the better version.

Example (made up): keyword "remote work", 24 top HN posts. P2, P7, P11, P19 open with a personal number ("After 5 years remote…") → pattern "years-of-experience opening", 4 pieces.
