# zero-budget-growth

方法來自吕白《从零开始做内容》ch07。要細節時讀 `~/.agents/skills/content-from-zero/chapters/ch07-app-growth-and-splash.md`（只讀，不要把內容抄進輸出）。

活動分三段：**拉得來**（資源＋渠道）→ **玩得動**（門檻＋節奏）→ **留得住**（獎勵）。每段都要有負責人、日期、要看的數字，計畫才算能執行。

## 0. 收集現況

向用戶問清楚（已給的不要再問）：產品和活動是什麼、目標用戶圈層、目標數字和期限、手上有哪些人和渠道、競品是誰。缺的先寫 `假設：...` 繼續做，最後列出來請用戶確認。

## 1. 拉得來：STAR 要資源

列出要向誰要什麼資源（站內曝光位、官方帳號、合作方、KOL）。對每個對象寫一段 STAR 請求：

- **S** 我方處境：要做什麼活動、誰參與、已談到哪些資源。
- **T** 目標：希望多少用戶參與。
- **A** 請對方做的具體動作，加時間點。
- **R** 對方得到什麼。這段最重要，要說到對方的 KPI 上，不打感情牌。

完成條件：每個資源對象一段可以直接發出去的 STAR 訊息。

## 2. 玩得動：觸達、門檻、節奏

- **精準觸達**：找目標圈層聚集的地方（微博超話、豆瓣小組、Discord、粉絲群、PTT 版），直接在那裡發；私聊最活躍的 5-10 人，拉群做用戶研究，問他們為什麼不參與。只服務對你最重要的那群人。
- **降門檻**：寫出參與最難的那一步（例：要出鏡、要寫字、要下載）。找一個競品或別的平台怎麼解決同樣的問題，照著改。
- **帶節奏**：設盟友關係（同一群人一起達成目標可解鎖獎勵）和競爭關係（每天公布各隊、各圈層的數字）。前期給一對一教程拉低門檻，後期再提高品質要求。

完成條件：列出 2-3 個觸達點、一個門檻改法和它抄的對象、一個盟友機制、一個競爭機制。

## 3. 留得住：榜單和獎勵

無償熱情約兩三週就消退，獎勵要在那之前上線。設計兩層：

- **給群體的獎勵**（隊伍、偶像、社團）：總榜前幾名得到曝光位、專題、官方背書。
- **給個人的獎勵**：日榜或週榜前幾名抽獎、徽章、限定權益。

獎品優先用零成本資源：站內曝光、官方轉發、榮譽身分、合作方提供的周邊。

完成條件：寫出榜單規則（統計什麼、多久更新、在哪公布）和每一層獎勵的來源與成本。

## 4. 輸出：成長計畫

```
# <活動名> 成長計畫
目標：<數字> / <期限>
假設（待確認）：...

| 階段 | 動作 | 負責人 | 日期 | 看的數字 | 達不到時怎麼辦 |
| 拉得來 | ... |
| 玩得動 | ... |
| 留得住 | ... |

附錄：STAR 訊息（每個資源對象一段）
```

完成條件：三段每段至少兩個動作；每個動作都有負責人（可寫角色）、日期、數字、備案；任何一格空著，計畫不交。
